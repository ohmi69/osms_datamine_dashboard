In data/, for both /current and /patches, the underlying subdirectories will have the following files:
cash_shop.json
crafting.json
items.json 
lookups.json 
maps.json 
monsters.json 
npcs.json 
skills.json 


For each directory
1. Each JSON file should not non-empty (not an empty array/object)
2. Each JSON file has entries with a name, and a thumbnail link
3. maps/ is populated and non empty
4. images/ is populated and non empty for each subdirectory
